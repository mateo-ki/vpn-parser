# VPN Parser

Rust + egui 写的 Windows 桌面程序：**采集**免费/自建订阅、**解析**成节点、**跑代理**、并把代理质量**测出来给你看**。

## 它突出的地方

**采集不止一种入口**
- 普通订阅 URL（支持 `YYYY-MM-DD` 日期占位符，逐日变化的链接不用手改）
- Gist 搜索页发现：扫 `vless://`、`ss://` 等关键词的结果页，把 gist raw 直接登记成订阅源
- Telegram 频道：读 `t.me/s/<频道>` 网页预览，正文里的**裸节点链接**和**订阅链接**两类都取；节点**只增不删**（累积模式，这一页没出现的老节点不会被清掉）

**测速以真实握手为准，并且敢说实话**
- 批量测速先 TCP 预筛，再经内核逐个访问 Google `generate_204` 计延迟；可选再做下载吞吐探测
- 出口健康条按最近 24 小时的**实测**画，不是看 `ProxyState` 挂绿勾 —— 内核日志里全是 `dial tcp i/o timeout` 而界面还绿着，这种事不再发生
- 出口切换记录落库保留 **90 天**，按**本地日**分组（含"该切但没找到替补"这种失败），重启不丢

**两层自动选路，互不打架**
- 内核层：`PROXY(select) → 自动选择(url-test) → 漏网之鱼`三组结构，换节点不重读配置、不断已有连接
- 应用层：故障转移调度器（EWMA + 断路器 + 滞后 + 最小切换间隔），只在真不通或持续劣化时换一次
- 替补池空了可以自动补一轮低并发全量测速（默认关，系统设置里勾）

**分流规则看得见命中**
- GEOSITE / GEOIP / 关键词 / 进程名（TUN 模式）等匹配器，规则可增删改
- 每天每条规则实际命中多少条连接，按 `(规则, 目标)` 聚合入库

**Windows 上把细节做完**
- 系统代理 / TUN（提权交接后只留一个实例）/ 终端 `HTTP_PROXY` 环境变量三条都管
- 按 exe 路径往防火墙加允许规则（重编译换 exe 不至于突然连不上）；单实例互斥；托盘
- 内核缺了直接把下载窗口开在你面前：两种镜像（gh-proxy / ghfast）、官方直连、走代理、本地导入，一次只走一条，不并发竞速

**其它**
- 本地 HTTP API（默认 `127.0.0.1:8080`，强制 bearer 鉴权）：列节点、拉订阅、触发测速、重启代理、查任务与统计
- 导出 mihomo / sing-box / xray 配置
- 界面全中文、5 套浅色主题、Ctrl+K 命令面板

## 协议支持

解析：`ss` `vmess` `vless` `trojan` `hysteria2/hy2` `socks5` `http(s)`，以及 Clash/Clash Meta YAML、Base64 与混合文本里的分享链接。
连接（内核决定）：以上再加 `tuic` `wireguard`。`anytls` `ssr` `mieru` `openvpn` `sstp` **存得下但连不上**，会在界面上标出来而不是静默丢弃。

## 快速开始

```bash
cargo run --release
```

数据都在程序目录的 `data/` 下：主库 `vpn-parser.db`（订阅源、设置、遥测），节点按源分片存 `data/subscriptions/*.db`（每次拉取整库重建再改名，所以遥测表刻意放在主库）。

打安装包：

```bash
cargo build --release
"<Inno Setup>\ISCC.exe" installer/vpn-parser.iss   # 产物在 dist/
```

## 上手三步

1. 系统设置里确认内核已装（没装会在你启动代理时自动开下载窗口）
2. 订阅源页加一条源（或跑一次 Gist / Telegram 频道发现），点拉取
3. 控制台点一个节点作为出口 → 启动代理。之后浏览器打不开境外时，先看表头那行实测健康，而不是看它有没有绿

## 已知边界

- 内核装在用户可写目录（`data/kernels`），TUN 提权时会以管理员执行其中的 exe —— 这是这类工具的固有暴露面
- url-test 只看"到测试 URL 的 HTTP 延迟"，不看带宽也不看落地 IP 信誉；要按带宽换节点得另开带宽保护开关
- 免费共享订阅失效极快，测通数量长期偏低是常态，不是本程序的 bug
