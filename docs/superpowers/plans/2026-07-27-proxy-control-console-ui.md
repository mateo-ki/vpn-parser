# 代理控制台 UI 实施计划

## 目标

将现有深色卡片式界面调整为已确认的浅色网络控制台，并让“代理运行”成为首个菜单和默认页面，同时保持现有代理、规则、DNS/TUN、内核与日志能力可用。

## 实施步骤

1. 调整默认页面和侧栏顺序，移除彩色 Emoji 导航。
2. 增加代理页内标签状态，拆分分流规则、DNS/TUN、内核与日志视图。
3. 重构代理首页顶部状态、当前节点、运行模式和连通性指标。
4. 统一浅色背景、石墨侧栏、青绿色强调色、边框和按钮样式。
5. 运行格式化、检查、测试和构建，并在 960x600 以上窗口验证布局和主要交互。

## 验收标准

- 应用启动后默认进入“代理运行”，且该菜单位于首位。
- 代理运行状态、当前节点、模式、端口和主要操作在首屏可见。
- 分流规则、DNS/TUN、内核和日志可通过页内标签访问。
- 现有配置保存、代理启停、节点切换和刷新功能不退化。
- 最小窗口无明显重叠或横向溢出，Rust 格式化、检查、测试和构建通过。
